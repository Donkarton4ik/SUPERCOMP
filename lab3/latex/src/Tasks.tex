\noindent
{\Large \textbf{\section{Постановка задачи}}} \par

Исследовать характеристики кэш-памяти собственного компьютера с помощью программы на языке C, используя косвенные измерения времени доступа к памяти. Необходимо:

\begin{enumerate}
    \item Определить размер каждого уровня кэша (первого, второго, третьего) в килобайтах.
    \item Определить размер строки кэша в байтах.
    \item Определить степень ассоциативности кэша (современные кэши являются множественно-ассоциативными, $k$-way set associative).
\end{enumerate}
